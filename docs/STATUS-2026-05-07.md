## Code Changes Applied

### Security
- OTP bypass: DB-only management, env vars removed
- Redis-based OTP rate limiter (was in-process memory)
- Rate limiting added to: register, change-password, checkout, referral
- Email validation via EmailStr
- JWT secret min_length=32, token revocation on password change
- Upload image processing constants (MAX_IMAGE_WIDTH, JPEG_QUALITY) — were missing causing silent failures
- Staff PIN update fix: `admin_user_id` → `user_id`
- SSRF protection on POS endpoint

### Performance
- N+1 query batching in: survey list, survey responses, voucher usages, reward redemptions, inventory item ledger
- Sync urllib → async httpx for geo-location

### Code Quality
- Pydantic v1 Config → ConfigDict migration (46 instances, 23 files)
- 9 orphaned compliance.py models deleted (DB tables remain)
- 2 dead endpoints removed (POST /admin/feedback, GET /admin/export)
- python-jose → pyjwt dependency swap
- zod removed from PWA package.json

### Frontend
- WCAG copper accent contrast fix (#9B6625)
- Sidebar CSS gradient → CSS variables
- Survey export JSON button, sales CSV export button
- Reward checkout fix (parseInt NaN bug)
