# Staff Portal: Reservations

## Page
`/reservations`

## Purpose
View and manage table reservations.

## Reservation statuses

| Status | Meaning |
|--------|---------|
| requested | Awaiting confirmation. |
| confirmed | Confirmed by staff. |
| seated | Customer has been seated. |
| no_show | Customer did not arrive. |
| cancelled_by_guest | Cancelled by customer. |
| cancelled_by_merchant | Cancelled by staff. |
| completed | Finished. |

## View reservations

1. Tap **Reservations** from the home screen.
2. See a list of reservations for the selected date.
3. Tap a reservation to open details.

## Create a reservation

1. Tap **New Reservation**.
2. Select date, time, and party size.
3. Select table if needed.
4. Enter customer name and phone.
5. Save.

## Confirm or cancel a reservation

1. Open the reservation detail.
2. Select the new status.
3. Save.

## Seating a reservation

1. When the customer arrives, open the reservation.
2. Tap **Seated**.
3. Optionally create a POS order linked to the table.

## Limitations
- Reservations are store-scoped.
- Some reservation management actions require admin access.
