# Staff Portal: Getting Started

## First login

1. Open the Staff Portal URL in a browser.
2. Enter your phone number or staff credentials.
3. Enter your PIN.
4. If you are an admin user, select the store you want to work in.

## Home screen

After login, you see the home dashboard with buttons based on your role.

| Button | Role needed | Purpose |
|--------|-------------|---------|
| POS | cashier, server, shift_supervisor, store_manager, admin | Create orders and take payments. |
| Kitchen | kitchen_staff, shift_supervisor, store_manager, admin | View and update kitchen orders. |
| Orders | all roles | View the order queue. |
| Tables | all roles | View table status and QR codes. |
| Reservations | all roles | View and manage reservations. |
| Inventory | shift_supervisor, store_manager, kitchen_staff, admin | Update stock levels. |
| Wastage | shift_supervisor, store_manager, kitchen_staff, admin | Report wasted stock. |
| Equipment | shift_supervisor, store_manager, kitchen_staff, admin | Check equipment condition. |
| Garbage | shift_supervisor, store_manager, kitchen_staff, admin | Log garbage disposal. |
| Grease Trap | shift_supervisor, store_manager, kitchen_staff, admin | Log grease trap cleaning. |
| Time Clock | all roles | Clock in/out and breaks. |
| Shifts | all roles | View upcoming shifts. |
| Tasks | all roles | Complete assigned tasks. |
| Wallet | all roles | Check or top up customer wallets. |
| Profile | all roles | View profile and change PIN. |

## Help icon

Tap the **Help** icon in the top header from any page to open this guide.

## Common workflow: create a dine-in order

1. Tap **POS**.
2. Choose **Dine-in**.
3. Select or scan a table.
4. Add items to the cart. Tap an item to add modifiers.
5. Apply a voucher or reward if the customer has one.
6. Tap **Charge** and choose payment method (Cash or Stripe QR).
7. Complete payment.

## Common workflow: kitchen order progression

1. New order appears in **Kitchen** under **Pending**.
2. Tap **Start** → status becomes **Preparing**.
3. Tap **Ready** → status becomes **Ready**.
4. Server collects and taps **Served** or delivers the order.

## Tips

- Always clock in at the start of your shift.
- If the POS shows a permission error, ask a supervisor or manager.
- Use the **Park** feature to hold an unpaid order.
- Keep your PIN secure; change it if you suspect someone knows it.
