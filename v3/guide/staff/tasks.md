# Staff Portal: Tasks

## Page
`/tasks`

## Purpose
View and complete assigned operational tasks.

## What you see

| Column | Description |
|--------|-------------|
| Task | Task title and description. |
| Due | Due date and time. |
| Priority | low, normal, high, urgent. |
| Status | pending, in_progress, completed, cancelled. |

## Complete a task

1. Open **Tasks**.
2. Find the task in the pending list.
3. Tap the task to view details.
4. Tap **Mark Complete**.
5. Add a note or photo if required.

## Task types

Tasks can be created by managers in the Admin Portal and may include:
- Opening checklist
- Closing checklist
- Cleaning tasks
- Maintenance checks
- Inventory counts

## Filter
- Pending
- Completed
- All

## Recurring Tasks

Tasks can be set to repeat automatically:
- **Daily tasks** (e.g. "Clean grease trap") auto-create the next occurrence when completed
- **Weekly tasks** (e.g. "Deep clean espresso machine") create a copy +7 days
- **Recur interval**: Admin sets the repeat interval in days when creating/editing a task
