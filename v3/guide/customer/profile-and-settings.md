## Profile page

### What you see
- Name and phone
- Loyalty tier and points
- Wallet balance
- Quick links to orders, rewards, wallet, reservations, etc.

### Edit profile
1. Tap **Account Details**.
2. Update name, email, date of birth, or avatar.
3. Save.

## Account Details page

### Change phone number
1. Open **Account Details**.
2. Tap **Change Phone**.
3. Enter new phone number.
4. Verify with OTP.
5. Save.

### Change password / PIN
If password login is enabled:
1. Open **Account Details**.
2. Tap **Change Password**.
3. Enter current and new password.
4. Save.

## Payment Methods page

### Saved cards
If card linking is enabled, you can save cards for faster checkout.

### Add a card
1. Open **Payment Methods**.
2. Tap **Add Card**.
3. Enter card details.
4. Save.

> Note: Card linking may be disabled depending on store configuration.

## Saved Addresses page

### Add an address
1. Open **Saved Addresses**.
2. Tap **Add Address**.
3. Enter address details.
4. Save.

### Set default
Tap the star icon next to an address to set it as default for delivery.

## Settings page

### Options

| Setting | Purpose |
|---------|---------|
| Language | Change app language (en, ms, zh, ta, tr). |
| Store | Change selected store. |
| Notifications | Enable or disable push notifications. |
| Marketing preferences | Opt in or out of marketing messages. |
| Dark mode | Toggle light/dark theme if available. |
| App version | View current version. |

## Legal page

View legal pages such as:
- Terms of Service
- Privacy Policy
- Refund Policy
- About Us

## Notifications page

### What you see
A list of push notifications and in-app messages.

### Mark as read
Tap a notification to open it, or tap **Mark All as Read**.
