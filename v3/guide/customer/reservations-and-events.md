# Customer PWA: Reservations & Events

## Pages
- `reservations` — Reservations
- `events` — Events

## Reservations page

### Make a reservation
1. Open **Reservations**.
2. Select store.
3. Select date, time, and party size.
4. Add special requests (optional).
5. Tap **Request Reservation**.
6. Wait for confirmation from the store.

### View reservations
- Upcoming reservations appear first.
- Past reservations are shown below.

### Cancel a reservation
1. Open the reservation.
2. Tap **Cancel**.
3. Confirm.

### Reservation statuses

| Status | Meaning |
|--------|---------|
| requested | Awaiting confirmation. |
| confirmed | Confirmed by the store. |
| seated | You have been seated. |
| cancelled | Cancelled by you or the store. |
| completed | Finished. |

## Events page

### What you see
Upcoming events hosted by the store or brand.

### Event details
- Title and description
- Date, time, and location
- Image
- RSVP status
- Capacity

### RSVP to an event
1. Open **Events**.
2. Tap an event.
3. Tap **RSVP**.
4. Enter party size if needed.
5. Confirm.

### Cancel RSVP
1. Open the event.
2. Tap **Cancel RSVP**.
3. Confirm.
