# Customer PWA: Menu & Ordering

## Pages
- `menu` — Menu
- Item detail / modifier sheet
- Bundle picker sheet
- `cart` — Cart

## Menu page

### Browse items
1. Tap **Menu** in the bottom navigation.
2. Scroll through categories.
3. Tap a category to filter items.
4. Tap an item to open details.

### Item detail

The item detail sheet shows:
- Item name and description
- Price
- Allergens and dietary tags
- Modifier groups
- Add to cart button

### Select modifiers

1. Tap an item.
2. Choose required options.
3. Choose optional add-ons.
4. Adjust quantity.
5. Tap **Add to Cart**.

### Bundle products

1. Tap a bundle item.
2. The bundle picker opens.
3. Select items for each course or pool according to the rules.
4. Tap **Add to Cart**.

## Cart page

### Review cart
1. Tap **Cart** in the bottom navigation.
2. Review items, modifiers, quantities, and prices.
3. Edit or remove items as needed.

### Add a note
Tap **Add Note** to leave a message for the kitchen or staff.

### Dine-in mode

For dine-in orders:
1. Tap the dine-in option.
2. Scan the table QR code or enter the table number.
3. The table is linked to your order.

### Apply voucher
1. Tap **Add Voucher**.
2. Enter the voucher code.
3. Tap **Apply**.

### Apply reward
1. Tap **Add Reward**.
2. Select an available reward from **My Rewards**.
3. Tap **Apply**.

### Cart totals

| Line | Description |
|------|-------------|
| Subtotal | Sum of item prices. |
| Modifiers | Cost of selected modifiers. |
| Discount | Voucher/reward discount. |
| Delivery fee | For delivery orders. |
| Tax | Tax based on store settings. |
| Service charge | If configured. |
| Total | Final amount to pay. |

### Proceed to checkout
Tap **Checkout** to continue.

## Tips

- Items marked out of stock cannot be added.
- Dietary tags help you identify suitable items.
- Tap the heart icon to save favourite items (if enabled).
